# Este es un template HTML para notificar a los administradores sobre la creación de un nuevo ticket de soporte por parte de un inquilino. El diseño es limpio y profesional, utilizando colores suaves y una estructura clara para resaltar la información importante del ticket. Se incluyen detalles como el número de ticket, el asunto, el usuario remitente y el mensaje del ticket, todo presentado de manera organizada para facilitar la lectura y acción por parte del administrador.

Asunto: {{ asunto }}

Usuario Remitente: {{ usuario }}

{{ mensaje }}
